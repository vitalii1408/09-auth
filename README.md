# NoteHub — Notes App with Authentication

A full-stack style note-taking application built with Next.js App Router. Users can sign up, log in and manage their personal notes in private routes. This is the final and most complete version of the NoteHub project.

## 🔗 Links

- **Live Demo:** [https://09-auth-11-644c.vercel.app](https://09-auth-11-644c.vercel.app)
- **Source code:** [github.com/vitalii1408/09-auth](https://github.com/vitalii1408/09-auth)

## 🛠 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- TanStack Query
- Zustand
- Axios
- CSS Modules
- Vercel

## ✨ Features

- Sign up / sign in / log out with cookie-based sessions
- Private and public routes protected by Next.js proxy (middleware)
- User profile page with profile editing
- Create and delete notes, view note details
- Filter notes by tags (parallel routes sidebar)
- Search with debounce and pagination
- Note preview in a modal via intercepting routes
- Server-side data prefetching with TanStack Query hydration

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/09-auth.git
cd 09-auth
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
